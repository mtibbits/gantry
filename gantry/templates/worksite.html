Schedule across agent lanes

All open leaves, linked or not, spread across parallel agent lanes. Each lane is one agent session working {{HOURS_PER_DAY}} agent-hours a day, and each leaf takes the midpoint of its estimate, or the default unit when it has none. When a lane comes free it takes the most urgent leaf that is ready; a leaf takes the priority of anything it unblocks, and WBS order breaks ties. This is one plausible plan, not a forecast.
