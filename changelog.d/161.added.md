- `python3 tools/next_requirement_id.py <code>` prints the next free
  requirement ID for a layer, counting `main`, the working tree, and open
  issues and pull requests by the owner, a member or a collaborator; it
  writes nothing and refuses rather than guess. `docs/requirements.md` now
  says to claim the ID in the issue's body and that the pull request merging
  second renumbers, and `docs/requirements-format.md` defines a number as
  used once it is on the default branch.
